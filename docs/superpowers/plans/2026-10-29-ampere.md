# Ampere Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement task by task.

**Goal:** Run Basalt correctly and efficiently on the local RTX 3090.
**Architecture:** Compile sm_86 CUDA; preserve existing Ampere-compatible kernels,
route unsupported specializations to tested native paths, then profile.
**Tech Stack:** C++20, CUDA 13.3, MSVC 19.44, CMake/Ninja, Python 3.12.
**Spec:** ../specs/2026-10-29-ampere-design.md (approved).

## Global Constraints
Keep platform seams and licenses. Do not change clocks, power limits or registry.
Use this checkout, the requested fork and a local virtual environment. User has
approved implementation and downloading the upstream IQ3_S model pack.

## Review Focus
- Kernels with architecture-guarded empty bodies must never be selected.
- Unsupported instructions must be absent from sm_86 assembly.
- FP4 dispatch and its buffer sizes must agree on hardware capability.
- GPU auto-selection must accept sm_86 and reject unsupported cards.
- Synthetic parity does not establish end-to-end model quality or throughput.
